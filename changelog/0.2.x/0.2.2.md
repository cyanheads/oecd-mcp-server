# 0.2.2 — 2026-08-10

## Security

- **`fetchOecd`** issues every request with `redirect: 'manual'` and refuses any 3xx as a terminal `Forbidden`, never retried. `externalServiceRoot()` pins a delegated service root to the configured base URL's origin, but that check bound only the first hop — under the platform's default `redirect: 'follow'`, a 3xx from the validated host could carry the request to any other origin. A base URL configured over plaintext now fails with an error naming `OECD_BASE_URL` instead of being silently upgraded to https ([#26](https://github.com/cyanheads/oecd-mcp-server/issues/26)).

## Fixed

- **`oecd_list_agencies`**, **`oecd_search_datasets`**, **`oecd_get_dataset_info`**, **`oecd_get_dimension_values`**, **`oecd_query_dataset`** — declare `upstream_redirect` (`Forbidden`, not retryable) and report the fetch boundary's own sentence via `refusedRedirectText()`. A redirect refusal previously reached two of these tools as an undeclared `Forbidden` with no recovery hint, and the other three relabeled it as a retryable `upstream_error` advising a wait that can never clear a misconfigured origin.
