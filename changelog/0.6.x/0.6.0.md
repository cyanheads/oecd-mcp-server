# 0.6.0 — 2026-10-28

## Added

- **oecd-guide skill**: the server publishes an Agent Skill covering SDMX key construction, confirming which series a dataflow carries, and reading results without mixing breakdowns, units, or country aggregates. It is served over MCP (`resources/list` gains `skill://oecd-guide/SKILL.md` plus the `skill://{+path}` template) and ships in the npm package, Docker image, and MCPB bundle.
- **Agent Plugins manifests**: root `plugin.json` and `mcp.json` for Codex, Cursor, GitHub Copilot, VS Code, and Kiro.

## Changed

- **Framework 0.13.17**: MCP SDK `@modelcontextprotocol/server` ^2.3.1 → ^2.4.0; canvas table re-registration is atomic, so a failed spill leaves the previous table ([mcp-ts-core#659](https://github.com/cyanheads/mcp-ts-core/issues/659)), and `spillover()` closes its source on every early exit ([#661](https://github.com/cyanheads/mcp-ts-core/issues/661)).
- **Framework 0.13.18**: `createApp({ skills })` serves the skill; enrichment trailer string values, such as the `oecd_get_dimension_values` query echo, render as code spans in `content[]` ([#785](https://github.com/cyanheads/mcp-ts-core/issues/785)); `escapeMarkdownInline` escapes a trailing ` #` ([#781](https://github.com/cyanheads/mcp-ts-core/issues/781)); the bundle cleaner strips the framework's build-only files from the `.mcpb` ([#791](https://github.com/cyanheads/mcp-ts-core/issues/791)).
- **`oecd_dataframe_query`** `row_count` is documented as the number of rows returned after the canvas row cap, not the full result count.
- **`oecd_dataframe_describe`, `oecd_dataframe_query`, `oecd_dataframe_drop`** descriptions say they are unavailable when DataCanvas is disabled, instead of naming `CANVAS_PROVIDER_TYPE=duckdb`.
- **`oecd_query_dataset`** `canvas_id` description states that a result fitting inline leaves the named canvas unchanged; the `no_results` recovery says to probe with empty segments and a single recent period, since a listed code may not occur in the dataflow.
- **`.mcpb` bundle** keeps the MCP SDK's `dist/ext/skills/` runtime, which the skills extension imports at boot; a local `scripts/clean-mcpb.ts` and `scripts/lint-packaging.ts` narrowing pins this in `tests/scripts/bundle-agent-docs.test.ts` ([mcp-ts-core#794](https://github.com/cyanheads/mcp-ts-core/issues/794)).
- **Development tooling** resyncs framework skills, scripts, issue templates, and `.mcpbignore`; `bunfig.toml` `minimumReleaseAge` drops from 3 days to 1 day; the Dockerfile OCI title is `oecd-mcp-server`; the README Getting started section is shorter; `docs/design.md` records OECD's 60-downloads-per-hour cap.

## Fixed

- HTTP deployments running under Bun (the Docker image's runtime) no longer grow memory with every request: 0.5.0 shipped on mcp-ts-core 0.13.16, which retained each request's abort signal, and 0.13.17 releases it when the response ends.
- **`oecd_get_dimension_values`** no-match notice escapes the caller's `query` and `dimension_id`, so Markdown punctuation in them reads back as written.
- **`oecd_query_dataset`** spill notice is emitted through the notice slot with the table name and `canvas_id` as code spans.
