# 0.1.4 — 2026-08-09

## Added

- **`oecd_search_datasets`** matches query tokens against dataflow descriptions as well as names, reports which field matched via `matched_in` (`name` | `description` | `both`), and returns each match's description truncated to 240 characters on a word boundary ([#14](https://github.com/cyanheads/oecd-mcp-server/issues/14)).
- **`oecd_search_datasets`** takes an optional `offset` to page through matches past `limit`; the capped-list `enrichment.totalCount` disclosure is now offset-aware, firing only when matches remain beyond the returned page ([#15](https://github.com/cyanheads/oecd-mcp-server/issues/15)).
- **`OecdDataflow`** carries `description`, parsed from the same localized-string shape as `name`. OECD authors it as HTML; tags are reduced to whitespace and the named entities present in the live catalog (`&nbsp;`, `&amp;`, `&rsquo;`, `&ndash;`, and accented-character references) are decoded.
- **`oecd_search_datasets`** gained an `agency_not_found` contract entry (`NotFound`, non-retryable) naming the offending `agency_id` and pointing at `oecd_list_agencies` ([#12](https://github.com/cyanheads/oecd-mcp-server/issues/12)).
- **`bunfig.toml`** blocks installing package versions published in the last 3 days (`minimumReleaseAge`) as a supply-chain guard, scanned by `@socketsecurity/bun-security-scanner`; `@cyanheads/mcp-ts-core` is exempted for same-day framework adoption.
- **`.env.example`** documents `CANVAS_TEMP_PATH` — the DataCanvas scratch root for DuckDB spills and exports.
- **`.github/SECURITY.md`** and **`.github/FUNDING.yml`** added.

## Changed

- **`enrichment.totalCount`** on `oecd_search_datasets` is now `.optional()` — a search whose matches fit inside `limit` no longer fails output validation ([#5](https://github.com/cyanheads/oecd-mcp-server/issues/5)).
- **Structure-service retries** now classify through `fetchWithTimeout`'s status-to-code mapping: a 404 fails on the first attempt as a terminal `NotFound` instead of costing three round trips, while 408/429/5xx keep retrying. Applies to `fetchDataflows`, `fetchDataStructure`, and `fetchCodelist` ([#12](https://github.com/cyanheads/oecd-mcp-server/issues/12)).
- **`429 Retry-After: 0`** from OECD's throttle no longer collapses the retry backoff — a zero-second hint is dropped so the exponential backoff still applies; a `Retry-After` naming a real wait is still honored.
- **Any `5xx`** from the structure API is restated as `ServiceUnavailable` instead of the terminal `InternalError`, so a server-side fault gets its retries.
- **`isDataflowNotFound`** classifies on the error code (`McpError` + `NotFound`) rather than string-matching `"HTTP 404"` in the message, fixing detection for `oecd_get_dataset_info`, `oecd_get_dimension_values`, and the `oecd://dataflow` resource.
- **`oecd_get_dimension_values`**'s `notice` field moved from `output` to `enrichment`, clearing a lint warning.
- **README** — removed stale PISA search claims, corrected `oecd_list_agencies` example agency IDs (`OECD.ELS`/`OECD.EDU` both 404; replaced with `OECD.SDD.NAD`, `OECD.ELS.SPD`, `OECD.EDU.IMEP`), rewrote the `oecd_search_datasets` bullet for description matching and offset paging, and clarified the `REF_AREA` codelist count is full only in `structuredContent` ([#8](https://github.com/cyanheads/oecd-mcp-server/issues/8)).
- **PISA** removed from `package.json` description/keywords and `.codex-plugin/plugin.json`'s `longDescription` — OECD renamed the dataflow, and none of the 1,544 live catalog entries match `PISA` in id, name, or description.
- **Dockerfile** production stage installs `--production` dependencies instead of copying the build stage's full `node_modules`, dropping the dev toolchain from the shipped image (888 MB → 664 MB); both stages add `--ignore-scripts` and a BuildKit cache mount for Bun's install cache, and pin `oven/bun:1.3.14`.
