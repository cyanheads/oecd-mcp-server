# 0.1.2 — 2026-06-06

## Fixed

- **`oecd_search_datasets` description** no longer leaks the caching implementation detail ("first call fetches the full catalog…subsequent calls are fast"). ([#1](https://github.com/cyanheads/oecd-mcp-server/issues/1))
- **`oecd_query_dataset`** response now echoes the effective query parameters (`query_flow_ref`, `query_key`, `query_start_period`, `query_end_period`) in both `structuredContent` and `content[]` text. ([#2](https://github.com/cyanheads/oecd-mcp-server/issues/2))
- **`oecd_get_dimension_values`** returns a `notice` field when a dimension has no codelist, explaining that the dimension accepts dynamic or free-form values and directing the caller to `oecd_query_dataset` for discovery. ([#3](https://github.com/cyanheads/oecd-mcp-server/issues/3))
- **`oecd_dataframe_describe` / `oecd_dataframe_query`** canvas-not-configured path now throws `ctx.fail('canvas_disabled', …)` against a declared `canvas_disabled` error contract (`ServiceUnavailable`, typed `data.reason`) instead of an undeclared `serviceUnavailable()` factory call. ([#4](https://github.com/cyanheads/oecd-mcp-server/issues/4))

## Changed

- `@types/node` ^25.9.1 → ^25.9.2
