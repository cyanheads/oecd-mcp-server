# 0.1.1 — 2026-06-05

Initial public release of `@cyanheads/oecd-mcp-server`. Provides 7 MCP tools and 1 resource over the [OECD SDMX REST API](https://sdmx.oecd.org/public/rest) — 1,500+ statistical datasets (national accounts, employment, trade, education, health) — with optional DataCanvas SQL support for large result sets. Keyless; no API key required.

## Added

- **`oecd_list_agencies`** — list OECD SDMX agencies with dataflow counts and total dataflow count
- **`oecd_search_datasets`** — search 1,500+ OECD dataflows by keyword across name, description, and agency; returns agency, DSD ID, dataflow ID, and description
- **`oecd_get_dataset_info`** — fetch dimension metadata for a dataflow including all dimension codes, names, codelist references, and position
- **`oecd_get_dimension_values`** — enumerate valid member codes and labels for a single dimension of a dataflow
- **`oecd_query_dataset`** — query OECD SDMX observations for a dataflow with a dimension key; large result sets spill to a named DataCanvas table (requires `CANVAS_PROVIDER_TYPE=duckdb`)
- **`oecd_dataframe_describe`** — list registered DataCanvas dataframes with schema, row count, and TTL (DataCanvas tools)
- **`oecd_dataframe_query`** — run single-statement SELECT SQL against DataCanvas dataframes via DuckDB (DataCanvas tools)
- **`oecd://dataflow/{agency_id}/{flow_id}`** resource — dimension metadata for a single OECD dataflow as JSON; `flow_id` is `{dsd_id}@{df_id}` with `@` percent-encoded as `%40`
- **`canvas-accessor.ts`** — DataCanvas instance accessor shared across tools
- **`Dockerfile`** — multi-stage build; copies `node_modules` from the build stage so `@duckdb/node-api`'s pre-compiled native binary is preserved in the production image without reinstalling build tools

## Security

- **`SDMX_ID_SAFE` regex** in `oecd-structure-service.ts` — validates `agencyId`, `dsdId`, and `dfId` path segments against `/^[A-Za-z0-9._-]+$/` before URL construction; rejects path-traversal sequences (`/`, `\0`, `?`, `#`) that could alter the URL structure
- **`SDMX_KEY_SAFE` regex** in `oecd-data-service.ts` — validates the dimension key string against `/^[A-Za-z0-9._+%-]*$/` before insertion into the data URL path; rejects characters that could alter URL path structure
- **Error sanitization** — removed `url` from `serviceUnavailable` error context objects and stripped upstream body content from 400/parse-error messages to prevent internal URL and API response leakage in error payloads
