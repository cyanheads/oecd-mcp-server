# 0.1.3 — 2026-06-12

## Added

- **`oecd_search_datasets`** discloses the full match count via an `enrichment.totalCount` block (`ctx.enrich.total(...)`) when the `limit` caps the returned list, so callers know how many dataflows matched before truncation.
- **`oecd_dataframe_query`** passes `denySystemCatalogs: true` to the DataCanvas query, blocking introspection of DuckDB system catalogs from caller SQL.
- **`Dockerfile`** — `APP_VERSION` build arg wired to an `org.opencontainers.image.version` OCI label, writable `/usr/src/app/.cache` and `/usr/src/app/.mirror` data dirs owned by the runtime user, and a bun-native `/healthz` `HEALTHCHECK`.
- **`check-framework-antipatterns` Rule 4** — flags `z.coerce.boolean()` on env flags (`Boolean("false") === true`); directs to `z.stringbool()`. Comment lines are skipped so documenting the pattern no longer trips the scan.

## Changed

- **`createApp()`** sets explicit `name` and `title` to `oecd-mcp-server` (display identity is the hyphenated repo name).
- **Error contracts** — `invalid_sql` (`oecd_dataframe_query`), `invalid_flow_ref` (`oecd_get_dataset_info`, `oecd_query_dataset`), and `invalid_key` (`oecd_query_dataset`) migrate from `JsonRpcErrorCode.InvalidParams` to `JsonRpcErrorCode.ValidationError`.
- **`bundle` script** runs `scripts/clean-mcpb.ts` after `mcpb pack` — prunes dev dependencies and strips dependency-shipped agent docs (`node_modules/**` `skills/`, `.claude/`, `.agents/`, `SKILL.md`) that root-anchored `.mcpbignore` patterns cannot reach.
- **`lint-packaging`** adds post-bundle content guards (zero `node_modules/**` agent-doc entries in a built `.mcpb`) and an identity check (`createApp()` `name`/`title` and manifest `display_name` equal the unscoped package name).
- **`.codex-plugin/plugin.json`** `interface.displayName` de-scoped to `oecd-mcp-server`; both plugin manifests bumped from `0.1.1` to `0.1.3`.
