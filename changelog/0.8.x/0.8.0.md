# 0.8.0 — 2026-11-25

## Added

- **`oecd_query_dataset`** `last_n_observations` (1 to 100,000): the latest N observations per series, sent as SDMX `lastNObservations` and echoed as `query_last_n_observations`. OECD applies it before `end_period`, so a `no_results` from the pair names that order and both recoveries: omit `end_period`, or drop `last_n_observations` and bound the window with `start_period` / `end_period` ([#55](https://github.com/cyanheads/oecd-mcp-server/issues/55)).
- **`oecd_get_dimension_values`** returns each code's `parent` (`codes[].parent`, omitted for top-level codes; a `Parent` column in `content[]` when a code on the page has one) and takes a `parent` filter, an exact match applied after `available_only` / `key` and before `query`, `offset`, and `limit`. A `parent` that matches nothing adds a notice, naming a parent that differs only by case ([#56](https://github.com/cyanheads/oecd-mcp-server/issues/56)).
- **`oecd_get_dataset_info`** and **`oecd://dataflow/{agency_id}/{flow_id}`** return the dataflow's `name`, full `description` as Markdown with `[label](url)` links, and `resources` (`{ label, url }[]` from its `EXT_RESOURCE` annotations), with no extra upstream request. The HTML-to-Markdown conversion keeps links whose unquoted `href` ends in `/`, reads quotes inside tags as HTML does (a quote opens a value only after `=`), recognizes every comment ending, escapes `\`, `[`, and `]` in link labels, percent-encodes `()<>` in `mailto:` recipients, and keeps a link after `!` from turning into image syntax ([#57](https://github.com/cyanheads/oecd-mcp-server/issues/57)).
- **`oecd_search_datasets`** `query` is optional: omitted or blank lists every dataflow in catalog order (within `agency_id` when set), and `matched_in` is omitted then ([#58](https://github.com/cyanheads/oecd-mcp-server/issues/58)).

## Changed

- **Breaking: `oecd_query_dataset`** no longer returns `content_table_capped` or `content_table_rows`. With DataCanvas off, `content[]` renders every row `structuredContent.rows` carries; with it on, a spill returns at most 25 preview rows beside `canvas_id` and `truncated: true`, where it returned up to 100,000 characters of rows. The 100,000-character threshold still decides when to spill ([#53](https://github.com/cyanheads/oecd-mcp-server/issues/53)).
- **`oecd-guide` skill** 1.3: periods and `last_n_observations`, `parent`, key-length rules, and listing with an omitted `query`.

## Fixed

- **`oecd_query_dataset`** and **`oecd_get_dimension_values`** check a key against the dataflow's dimension count before calling OECD, which dropped an extra segment on `/data` and refused it on `/availableconstraint` with HTTP 403. Extra trailing empty segments are trimmed (`query_key` echoes the trimmed key), and too few segments or a non-empty segment past the count fail `invalid_key`. `oecd_query_dataset` reads the count from the cached structure (0 requests warm, 1 cold, 2 to 4 cold for a dataflow delegated to another service root) and fails a `start_period` after `end_period` as `invalid_period`. On `oecd_get_dimension_values`, which takes no period, the extra-segment `invalid_key` message points periods at `oecd_query_dataset`'s `start_period` / `end_period` ([#54](https://github.com/cyanheads/oecd-mcp-server/issues/54)).
- **`oecd_search_datasets`** descriptions, which search matches against, come from the same HTML scanner as `oecd_get_dataset_info`'s: a bare `<` that opens no tag (`< 3 months`) stays, where the old tag strip deleted it along with the text up to the next `>`; `<style>`, `<head>`, and `<script>` contents are dropped; and text joins across an inline tag without a space (`CO<sub>2</sub>` reads `CO2`) ([#57](https://github.com/cyanheads/oecd-mcp-server/issues/57)).
