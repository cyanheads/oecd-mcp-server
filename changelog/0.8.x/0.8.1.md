# 0.8.1 — 2026-11-28

## Added

- **Period-specific availability.** Pass `start_period` or `end_period` to `oecd_get_dimension_values` to filter codes by availability and see the count for the requested window. The result echoes the applied bounds separately from OECD's reported `time_range`. ([#67](https://github.com/cyanheads/oecd-mcp-server/issues/67))
- **Dataflow editions.** Pass `version` to dataset info, dimension values, or dataset query to carry the edition through the datastructure, codelists, concept schemes, availability, and observation reads. A datastructure can have its own revision. Results identify the flow edition when confirmed, and dataset info can list published editions. ([#68](https://github.com/cyanheads/oecd-mcp-server/issues/68))
- **Delegated observation requests.** `oecd_query_dataset` sends its first data request to the delegated data root learned during key validation, even when the datastructure and labels come from another root. ([#70](https://github.com/cyanheads/oecd-mcp-server/issues/70))
- **Latest observations.** `last_n_observations` above 100,000 is served at that cap by default, with the applied value and a notice. Set `OECD_CLAMP_LIMITS=false` to advertise and enforce the input maximum. ([#71](https://github.com/cyanheads/oecd-mcp-server/issues/71))

## Changed

- **`oecd-guide` 1.4** covers edition selection, historical availability, and interpreting query notices. Development checks and bundle cleanup follow the updated framework tooling.

## Fixed

- **Dataflow descriptions** preserve paragraphs, lists, links, and table cells, including empty cells. ([#60](https://github.com/cyanheads/oecd-mcp-server/issues/60))
- **Requested-code coverage.** Query notices name explicitly selected codes missing from any dimension whose coverage can be established from the full observations, before constant columns are hoisted or a canvas preview is sliced. ([#61](https://github.com/cyanheads/oecd-mcp-server/issues/61))
- **SDMX response validation** recognizes malformed success bodies as `upstream_unreadable` and preserves the existing outcomes for valid empty collections. ([#62](https://github.com/cyanheads/oecd-mcp-server/issues/62))
- **Observation and SQL tables** switch to JSON text when empty strings appear alongside null or missing values anywhere in the rows. ([#63](https://github.com/cyanheads/oecd-mcp-server/issues/63))
- **`download_limit`** is retryable. Recovery distinguishes waiting for the hourly quota from narrowing an oversized request and carries OECD's `Retry-After` when supplied. ([#64](https://github.com/cyanheads/oecd-mcp-server/issues/64))
- **Dot-only keys** continue to select every series and carry a notice when their segment count differs from the dataflow's dimension count. ([#65](https://github.com/cyanheads/oecd-mcp-server/issues/65))
- **Failed label lookups** are reported on agency listings, dataset info, and dataflow resources while retaining IDs and labels that were available. ([#69](https://github.com/cyanheads/oecd-mcp-server/issues/69))
- **Period validation** treats blank bounds as unset and reports an impossible calendar day before comparing the bounds. ([#72](https://github.com/cyanheads/oecd-mcp-server/issues/72))
