# 0.3.1 — 2026-08-25

## Changed

- **`@cyanheads/mcp-ts-core` 0.12.3 adoption** serves MCP protocol revision 2026-07-28 alongside existing clients, advertises strict tool inputs (`additionalProperties: false`) and an `outputSchema` declaring the error envelope, renders input-validation failures as flat `path: message` sentences, rejects an unknown tool with `-32602`, and forwards `ctx.log` output to clients as `notifications/message`.
- **TypeScript configuration** splits `tsconfig.json` (typechecks `src/` and `tests/` together) from `tsconfig.build.json` (build emission scoped to `src/` only).
- **Docker image** pins Bun 1.4.0 in both stages, builds with `--platform=$BUILDPLATFORM`, and installs with `--omit=peer` to skip the framework's optional peer tiers.
- **`.env.example`** documents `MCP_SESSION_MODE=stateless` as this server's setting (DataCanvas handles are keyed by `canvas_id`, not session) plus the new `MCP_HTTP_RESUMABILITY*` settings.
- **Project guidance and skills** sync the framework's 0.12.x API references and conventions.

## Fixed

- **`bun run tree` directory-ignore patterns** (e.g. `.claude/`) now match only directories, not same-named files, so ignored directories stay out of `docs/tree.md`.
