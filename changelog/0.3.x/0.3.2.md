# 0.3.2 — 2026-09-20

## Changed

- **`@cyanheads/mcp-ts-core` 0.13.6 adoption** closes tool error text with the `(reason … · retryable)` terms and a `Recovery:` line a caller branches on, drops the upstream request URL from client-facing `error.data`, and declares `sessionMode: 'stateless'` in source rather than leaving it to `MCP_SESSION_MODE`.
- **`oecd_dataframe_describe`, `oecd_dataframe_query`, and `oecd_query_dataset`** take `canvas_id` via the framework's `CanvasIdSchema`, so the minted 10-character shape is visible in `inputSchema`.
- **`engines.bun` floor rises to `1.4.0`.**

## Fixed

- **A caller that disconnects mid-call is classified as a cancellation**, not an OECD upstream failure — `RequestCancelled` joins the codes `upstreamRefusal` declines to attribute to OECD.
- **A malformed `canvas_id` now fails argument validation** instead of reaching the canvas and reporting a missing or expired one.
- **`oecd_dataframe_query` separates a DuckDB execution error from a rejected statement** — a `SELECT` that parses and then fails on the data (a bad cast, an out-of-range value) now reports `sql_execution_error` with TRY_CAST/filter advice, rather than the "only SELECT is allowed" hint meant for a rejected statement.
